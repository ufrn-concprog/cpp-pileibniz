Detailed Description

Computes one term of the Leibniz series and synchronizes with peers.

Each instance is intended to run in its own thread. It writes the term for its index into the corresponding element of the shared terms vector, then waits until all participating threads reach the barrier.

void CalcThread::operator() ( )

Computes and stores this worker's term, then waits at the barrier.

Calculates the indexed Leibniz-series term and synchronizes.

The term is 4 * (-1)^index / (2 * index + 1). It is stored at its matching index in the vector before the worker waits for the other threads.
